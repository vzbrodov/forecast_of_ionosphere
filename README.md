# Прогнозирование полного электронного содержания ионосферы Земли (TEC) с использованием сферических гармоник

## Общее описание

Этот проект предназначен для прогнозирования полного электронного содержания (TEC) ионосферы Земли на основе исторических данных за 25 лет (1999-2023). Данные представлены в виде 256 коэффициентов сферических гармоник с временным разрешением 2 часа.

## Структура проекта

### Основные файлы:
- `tec_forecast.py` - основной скрипт прогнозирования
- `spherical_harmonics.py` - работа со сферическими гармониками
- `tec_map.py` - создание карт TEC
- `1999-2022rawdata` - исходные данные

## Как работает код

### 1. Загрузка данных
```python
# Загружаем данные из файла
# Формат: 1 столбец - дата, 256 столбцов - коэффициенты сферических гармоник
# Временное разрешение: 2 часа
# Период: 1999-2023 (109,572 записи)
```

### 2. Структура данных
Каждый коэффициент имеет индекс `i = n² + 2k + p - 1`, где:
- `n` - степень сферической функции (0-15)
- `k` - порядок (0-n)
- `p` - тип: 0 для sin, 1 для cos

### 3. Алгоритм прогнозирования

#### Шаг 1: Анализ временных рядов
Для каждого из 256 коэффициентов:
- Загружаем временной ряд (109,572 точки)
- Вычисляем статистики (среднее, стандартное отклонение)
- Определяем тренд (линейный полином)

#### Шаг 2: Создание прогноза
Для каждого коэффициента:
1. **Базовое значение**: последнее известное значение
2. **Тренд**: очень маленький линейный тренд на основе последних 10 точек
3. **Шум**: случайный шум (2% от стандартного отклонения)
4. **Сезонность**: небольшая циклическая компонента (суточный цикл)
5. **Ограничения**: значения ограничены диапазоном [среднее ± стандартное отклонение]

#### Шаг 3: Восстановление карты TEC
Используя формулу:
```
TEC(λ, φ) = Σ Σ P̃_nk(sin φ) * (a_nk cos kλ + b_nk sin kλ)
```
где:
- `P̃_nk` - нормированные полиномы Лежандра
- `a_nk, b_nk` - коэффициенты сферических гармоник
- `λ` - долгота, `φ` - широта

### 4. Создание карт

#### Карта последних данных
- Использует последние доступные коэффициенты
- Показывает текущее состояние ионосферы

#### Карты прогноза
- 5 дней: краткосрочный прогноз
- 10 дней: среднесрочный прогноз  
- 15 дней: долгосрочный прогноз
- 20 дней: долгосрочный прогноз

## Текущий алгоритм прогнозирования

```python
for каждый_коэффициент:
    # Базовое значение
    base_value = последнее_известное_значение
    
    # Очень маленький тренд
    trend = линейный_тренд_из_последних_10_точек * 0.1
    
    # Минимальный шум
    noise = случайное_число * 0.02 * стандартное_отклонение
    
    # Сезонность
    seasonality = 0.01 * sin(2π * день / 12) * стандартное_отклонение
    
    # Итоговый прогноз
    прогноз = base_value + trend + noise + seasonality
    
    # Ограничения
    прогноз = clip(прогноз, среднее - стд_откл, среднее + стд_откл)
```

## Физическая интерпретация

### TEC (Total Electron Content)
- Измеряется в TECU (1 TECU = 10¹⁶ электронов/м²)
- Типичные значения: 0-100 TECU
- Максимум в экваториальной области
- Минимум на полюсах
